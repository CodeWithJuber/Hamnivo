contribution. It is adapted, in plain English, from the Apache Software Foundation's Individual
Contributor License Agreement (version 2.2). You keep the copyright in your contribution: this
is a licence, not a transfer of ownership.

You sign it once, for all your contributions, by posting the comment the CLA check asks for on
your first pull request (see "How to sign" below).

- **"Contribution"** means any work of authorship, including code, documentation, designs,
  translations and tests, that you intentionally submit to the Owner for inclusion in the Project:

## How to sign

1. Open a pull request.
2. The **CLA** check posts a comment asking you to sign. If you agree to this agreement, reply on
   the pull request with exactly:

   ```
   I have read the CLA Document and I hereby sign the CLA
   ```

3. The check records your GitHub username, the time and the pull request in the
   `cla-signatures` branch of the repository, and passes. Your later pull requests pass without a
   new comment.

If the check does not update, comment `recheck`. Every person who authored a commit in the pull
request signs for themselves. If a commit's author email is not linked to a GitHub account, add
the email to your GitHub account or rewrite the commit with one that is.

If you contribute on behalf of your employer, make sure you have their permission first
(section 4). A company that wants to sign for its employees can contact the Owner through
[@CodeWithJuber](https://github.com/CodeWithJuber).
